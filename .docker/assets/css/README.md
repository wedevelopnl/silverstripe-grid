# Vendored CSS Assets

## Bootstrap

- **File:** `bootstrap.min.css`
- **Version:** 5.3.8
- **Source:** https://github.com/twbs/bootstrap/releases/tag/v5.3.8

To update, download the new `bootstrap.min.css` from the release page and replace the file here.

## Tailwind

- **File:** `tailwind.min.css`
- **Generated by:** Tailwind CSS v4 CLI (`@tailwindcss/cli`, pinned in the repo `package.json`)
- **Source:** `tailwind/input.css`

Unlike Bootstrap, Tailwind is JIT: it only emits the utility classes it finds by
scanning content. The testbed renders server-side with no source for Tailwind to
scan, so `tailwind/input.css` force-generates the grid's class surface via
`@source inline(...)`, across a numeric range wider than the default 12-column /
5-viewport topology so in-range project overrides still render.

Regenerate after editing `tailwind/input.css` (or bumping Tailwind):

```sh
npx @tailwindcss/cli \
  -i .docker/assets/css/tailwind/input.css \
  -o .docker/assets/css/tailwind.min.css --minify
```

Both files are baked into the image at build time (`Dockerfile` COPYs `assets/css/`
into `/app/public/css/`), so rebuild with `task build` after regenerating. The
entrypoint symlinks `grid-framework.css` to the file matching `SS_GRID_ADAPTER`.
